# Sans

<img src="sans-1024.png" width="128" alt="Sans icon">

A macOS app to preview sample text across all your installed fonts.

<img src="web/shot.png" alt="Sans screenshot">

Requires macOS 15 (Sequoia) or later.

## Install

1. Download [Sans.zip](https://github.com/vladstudio/sans/releases/latest/download/Sans.zip)
2. Unzip and drag `Sans.app` to `/Applications`
